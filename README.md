# Obsidian → mp3

Загружаешь свои заметки из Obsidian, получаешь mp3 и слушаешь их с телефона.
Озвучка через бесплатные нейроголоса Microsoft Edge (`edge-tts`), хорошо читает русский.

## Что нужно

- **Python 3.10 или новее** — [python.org/downloads](https://www.python.org/downloads/).
  При установке на Windows обязательно поставь галочку **«Add python.exe to PATH»**.
- Интернет (голоса синтезируются на сервере Microsoft, ключи и регистрация не нужны).

Больше ничего: ни ffmpeg, ни аккаунтов.

## Установка и запуск

### Windows

1. Склонируй репозиторий или скачай zip и распакуй.
2. Запусти `setup.bat` — создаст виртуальное окружение и поставит зависимости (один раз).
3. Запусти `run.bat`.
4. Открой в браузере `http://127.0.0.1:8000`.

При первом запуске Windows может спросить про брандмауэр — нажми «Разрешить»,
иначе телефон не достучится до компа.

### Linux / macOS

```bash
bash setup.sh
bash run.sh
```

### Вручную

```bash
pip install -r requirements.txt
python app.py
```

## Как пользоваться

1. На странице выбери `.md` файлы (можно сразу много) или `.zip` с папкой/целым хранилищем Obsidian.
2. Выбери голос и скорость, нажми **«Озвучить»**.
3. Готовые заметки появляются в списке: встроенный плеер, кнопка «скачать mp3»
   и «текст» (ровно то, что читает голос).

Из zip берутся только `.md`, служебные папки `.obsidian` и `.trash` пропускаются.

## Слушать с телефона

Сервер при старте печатает адрес вида `http://192.168.x.x:8000`. Телефон должен быть
в той же Wi-Fi сети.

- **Через браузер**: открой этот адрес с телефона — тот же список, плеер и скачивание.
- **Через подкаст-приложение** (AntennaPod на Android, Apple Podcasts / Overcast на iOS):
  «добавить подкаст по URL» → вставь `http://192.168.x.x:8000/feed.xml`.
  Каждая заметка станет эпизодом, их можно скачать и слушать офлайн.

Чтобы слушать не только дома, подойдёт [Tailscale](https://tailscale.com/):
ставишь на комп и телефон, и адрес компа работает из любой сети.

## Голоса

По умолчанию Светлана (ru). Есть Дмитрий (ru), английские и украинский — список в `app.py`,
словарь `VOICES`. Все доступные голоса: `python -m edge_tts --list-voices`.

Сервис Microsoft иногда «молчит» на отдельных голосах (замечено у Дмитрия).
Приложение делает две попытки, затем переключается на запасной голос и пишет об этом в карточке.

## Что делается с Markdown

`md_clean.py` превращает заметку в текст для чтения:

- убирает frontmatter, блоки кода, формулы, картинки, URL, HTML, комментарии `%% %%`;
- `[[wiki-ссылки]]` и `[ссылки](url)` заменяет на их текст;
- снимает разметку списков, чекбоксов, таблиц, цитат и callout;
- заголовки и строки без точки получают точку, чтобы голос делал паузы.

## Структура

```
app.py              сервер (FastAPI): загрузка, очередь озвучки, плеер, RSS-фид
md_clean.py         очистка Markdown
templates/index.html страница
data/               появляется при работе: mp3, тексты, library.json (в git не попадает)
```
